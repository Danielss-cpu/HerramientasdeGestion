# Herramientas de Gestión

Repositorio creado para evidenciar el uso de herramientas de gestión de proyectos y control de versiones mediante GitHub.

## Proyecto documentado
Web Integral

## Objetivo
Aplicar buenas prácticas de documentación, organización de recursos y trabajo colaborativo utilizando GitHub.

## Estructura del Repositorio
- `codigo_fuente/`: Contiene los componentes y lógica de la aplicación web (ej. `header.tsx`, `route-transition.tsx`).
- `documentacion/`: Documentos de referencia como manuales de instalación y normas del proyecto.
- `recursos/`: Archivos multimedia, como logos y mockups del diseño.
